[已修复] BUG:开关类按钮在开启状态下鼠标悬停会蓝色背景会消失
  → 根因: WPF-UI 4.3.0 ToggleSwitch 模板引用了 AccentFillColorSecondary/Tertiary 作为 Color 资源，
    但 Accent.xaml 仅定义了 Brush 变体 (*Brush)，DynamicResource 找不到 Color 导致画刷透明。
  → 修复: 在 MainWindow.xaml Window.Resources 中补充缺失的 Color 资源定义。

  → DanmakuItem.cs: 新增 SCBackgroundColor, SCBackgroundBottomColor, SCBackgroundPriceColor 属性
  → DanmakuEngine.cs: 使用 B站 API 提供的 time (秒) 作为持续时间，无 API 值时回退到 config
